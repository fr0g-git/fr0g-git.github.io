滲透測試中的 Nmap 使用方法論，涵蓋防火牆繞過、掃描策略、服務識別與 NSE 腳本。基於 HTB Academy Firewall/IDS Evasion 模組實戰經驗。

一、掃描前：判斷防火牆類型（永遠第一步）

nmap -sA -Pn -n -p <ports> <target>
結果代表難度
全部 unfilteredStateless packet filter好繞
全部 filteredStateful firewall需要更多技巧

二、主機發現

# 只做主機發現，不掃 port（速度快）
nmap -sn <network/CIDR>

# 從檔案匯入目標清單
nmap -iL targets.txt

三、防火牆繞過技巧

3.1 Source Port 偽裝（最有效的單一技巧）

nmap -sS -Pn -n --source-port 53 -p <ports> <target>

許多防火牆允許來源 port 53（DNS 回應）流量通過。

CPTS 考試重點： --source-port 53 是最常考的繞過技巧。

3.2 封包分片（謹慎使用）

nmap -f <target>           # 8-byte 分片
nmap -f -f <target>        # 16-byte 分片
nmap --mtu 24 <target>     # 自定義 MTU（必須是 8 的倍數）

⚠️ 重要陷阱：-f 會導致 -sV 回傳 tcpwrapped。-f 只用於 port 發現，不要跟 -sV、-sC、-sCV 混用。

3.3 Decoy 掃描

nmap -D RND:10 <target>                   # 10 個隨機假來源
nmap -D 10.0.0.1,10.0.0.2,ME <target>    # 指定 decoy + 自己

3.4 其他偽裝技巧

nmap --data-length 50 <target>    # 附加隨機資料改變封包大小
nmap --ttl 64 <target>            # 偽裝成特定 OS 的 TTL
nmap --badsum <target>            # 故意送錯 checksum（測試 IDS）
nmap -6 <target>                  # IPv6（很多 IDS 規則只針對 IPv4）

3.5 Idle Scan（殭屍掃描）

# 找殭屍主機（IPID 遞增的主機）
nmap --script ipidseq <candidate>

# 執行殭屍掃描（完全不從自己 IP 發封包）
nmap -sI <zombie_host> <target>

四、掃描策略與速率控制

# 低噪音掃描
nmap --scan-delay 5s --max-rate 5 <target>

# 全 port 掃描甜蜜點
nmap -p- --min-rate 100 --max-rate 200 <target>
Template全 port 時間備註
-T0~227 天不實際
-T1~11 天不實際
-T28-20 小時勉強可用
-T320-40 分鐘預設值
-T45-15 分鐘常用

五、掃描類型

參數用途
-sSSYN 半開放掃描（預設，需 root）
-sTTCP connect 全連接掃描
-sUUDP 掃描
-sAACK 掃描（判斷防火牆類型）
-sN / -sF / -sXNULL / FIN / Xmas 掃描
-sn主機發現（不掃 port）

六、服務與系統識別

nmap -sV <target>              # 服務版本偵測
nmap -sC <target>              # 預設 NSE 腳本
nmap -sCV <target>             # 版本 + 預設腳本（常用組合）
nmap -O <target>               # OS 偵測

七、NSE 腳本引擎

# 單一腳本
nmap --script <script_name> <target>

# 多個腳本（逗號分隔）
nmap --script banner,smtp-commands <target>

# 整個類別
nmap --script vuln <target>

# 自定義 User-Agent
nmap --script-args http.useragent="Mozilla/5.0 ..." <target>
類別說明
auth判斷驗證憑證
brute以憑證暴力破解登入對應服務
default使用 -sC 時執行的預設腳本
discovery評估可存取的服務
exploit嘗試利用已知漏洞
vuln識別特定漏洞
safe不執行侵入性和破壞性存取的防禦性腳本

八、輸出格式

# 同時輸出三種格式（最常用）
nmap -oA <basename> <target>

# XML 轉 HTML（方便閱讀）
xsltproc output.xml -o output.html

九、tcpwrapped 排查流程

當 -sV 回傳 tcpwrapped（TCP 握手成功但服務沉默）：

  1. 移除 -f — 分片是最常見的成因
  2. NSE 探測： 
    nmap --source-port 53 -Pn -n -p <port> \
     --script=banner,http-title,http-headers <target>
  3. 手動 nc 探測： 
    sudo nc -s <your_vpn_ip> -p 53 <target> <port>
  4. curl 探測： 
    sudo curl -v --local-port 53 http://<target>:<port>/
sudo curl -vk --local-port 53 https://<target>:<port>/

十、實戰組合指令

# 低噪音 Port 發現
nmap -sS --source-port 53 -Pn -n \
     --scan-delay 5s --max-rate 5 \
     --data-length 24 -p <ports> <target>

# 服務識別（不帶 -f）
nmap -sCV --source-port 53 -Pn -n -p <open_ports> <target>

# 全功能低噪音掃描
nmap -sS -T2 --source-port 53 -f --data-length 24 \
     --scan-delay 5s --max-rate 5 -Pn -n \
     -p 21,22,80,443,445,3389,8080 <target>

十一、CPTS / CDSA 考試重點

CPTS（攻擊端）：

  • --source-port 53 + -Pn + -sS 組合必考
  • -sA 判斷防火牆類型是解題第一步
  • -f 只用於 port discovery，不用於 service detection

CDSA（防禦端）：

  • Source port 53 的非 DNS 流量 → 明顯異常指標
  • 大量來自不同 IP 但時間一致的 SYN → Decoy scan 特徵
